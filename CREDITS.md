# Credits

Starbreak Salvage is built from original project code, text, and placeholder visuals created for this repository.

## Project

- Game design, implementation, docs, and release packaging: Starbreak Salvage contributors.
- Agent-assisted implementation notes and seed docs: original text created for this repository.

## Art and Audio

- Current game visuals are original Canvas 2D shape rendering and procedural starfield placeholders.

- No commercial game sprites, names, music, characters, UI, or proprietary data are included.
- Audio systems are not yet implemented; future audio must remain original, generated, or license-compatible.
