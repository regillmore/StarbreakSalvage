# Starbreak Salvage Seed Pack

This seed pack contains project instructions, design docs, architecture notes, backlog, and agent work orders for building **Starbreak Salvage** from an empty GitHub repository into a complete browser-based vertical scrolling roguelike shooter.

Recommended copy order into the repository:

1. Copy `AGENTS.md` to the repository root.
2. Copy the `docs/` directory into the repository root.
3. Start with the first work order in `docs/STARBREAK_SALVAGE_AGENT_WORK_ORDERS.md`.
4. Use `docs/STARBREAK_SALVAGE_BACKLOG.md` to create GitHub issues or drive Codex tasks.

The consolidated document `docs/STARBREAK_SALVAGE_AGENT_SEED.md` contains the full plan in one file. The other documents split the same plan into more practical working references.
